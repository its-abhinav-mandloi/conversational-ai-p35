# Technology Choices & Trade-Offs — P35: Agricultural Knowledge Navigator

| Layer | Selected Technology | Why It Fits P35 | Offline Fallback |
|---|---|---|---|
| **API Framework** | Python 3.12 + **FastAPI** + Pydantic v2 | Provides strict typed request/response contracts (`ChatRequest`, `ChatResponse`, `TurnTrace`), automatic OpenAPI `/docs`, and clean HTTP status handling (400/404) needed to reproduce every scenario deterministically. | Runs completely locally via `uvicorn` or `TestClient`. |
| **Persistence** | **SQLite** (`sqlite3` with parameterized SQL) | Zero-configuration ACID datastore ideal for single-node Phase I persistence of `sessions`, `active_crop_type`, `pending_clarification`, bounded `messages`, and JSON `trace_events`. | Built into Python standard library; no external DB server required. |
| **L6 Embeddings** | **sentence-transformers** (`all-MiniLM-L6-v2`, 384-dim) | Lightweight (~90 MB), fast CPU/MPS inference, strong semantic matching between user symptom phrasing (e.g., *"leaves turning yellow"*) and agronomic terms (*"chlorosis"*). | Uses local HuggingFace cache (`local_files_only=True`); `HashedNgramEmbedder` (`AGRI_EMBEDDING_BACKEND=hashed-local`) also exists for air-gapped environments without model weights. |
| **L6 Vector Index** | **ChromaDB** (`PersistentClient`, cosine space) | Directly aligned with Appendix-A P35 suggested stack (`Python, Chroma, LLM`); supports metadata filtering (`crop_type` in `[crop, "general"]`) and persisted HNSW cosine search. | Persists locally to `data/processed/chroma_db` and rebuilds deterministically from `data/raw/*.md`. |
| **L7–L8 Grounded RAG** | Deterministic extractive composer (`local-only`) + optional `openai`/`ollama` adapter | Guarantees reproducible, zero-cost, evidence-only responses with verified `[DOC-ID#sec-N]` inline citations and non-prescriptive educational disclaimers without requiring external API keys. | `local-only` is the default runtime mode; optional `openai`/`ollama` providers catch `ProviderUnavailableError` and fall back to `local-only` safely. |
